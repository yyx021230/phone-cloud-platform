# 批次服务发布准备（HTTP / Compose）

2026-10-28 候选；本文件不是已发布回执，也不执行生产变更。沿用 D-079 和主平台既有网络，新增服务默认不启动、计划默认关闭。旧 systemd 模板为另一种运行方式，不能同时启动两个实例。

## 拓扑和受限输入

- 推荐与根 Compose 同项目、同网络运行 `xhs-batch`。`platformBaseUrl` 配为 `http://phone-cloud:8787`，这是本仓 Compose 的服务名与容器端口；部署前与实际配置核对，服务名不同则调整受限配置。
- 批次容器内 `XHS_BATCH_HOST=0.0.0.0`，宿主只映射 `127.0.0.1:8791`。平台现有 HTTP/80 入口仅为 `/api/v1/open/xhs-data/` 代理至该回环端口，不将批次服务直接暴露公网。`nginx-location.conf` 是新增片段，不能覆盖整个站点。
- `XHS_BATCH_IMAGE` 必须为经过测试的不可变镜像；与平台同镜像，命令改为 `node server/xhs-batch/main.mjs`，不启动 Agent。
- `XHS_BATCH_DATABASE_URL` 连接当前 Compose PostgreSQL 的专用库/角色或已审核共享库；连接串只通过受限发布环境注入。新增两张表由发布步骤显式应用 `schema.sql`，应用启动不会自动迁移。
- `XHS_BATCH_CONFIG_PATH` 指向仓外绝对路径，JSON 结构见 `config.example.json`，真实密钥不得进入仓库。使用不同的专用普通平台用户，按当时最新设备 ID/appSlot/xhsId 制作名单；昵称不作为身份。容器以 `node` 用户运行，挂载文件应由该镜像的用户 UID 可读且权限为 `0600`，目录最小遍历权限；在暂存目录制作，不改变既有生产文件权限。
- 宿主只代理既定路径，原控制/WebSocket/媒体路由不变。SDK 和平台客户端支持 HTTP/HTTPS，签名、防重放、禁止重定向、未知提交不重复下发保持。HTTP 不提供传输加密。

## 发布前要完成的检查

1. 绑定提交、标签、镜像 ID/架构、清单 SHA256；用当前 ACTIVE、Compose、挂载、镜像、Agent/采集器实际哈希核对，不从旧候选推断生产。
2. 备份数据库、既有应用镜像、目标配置和受影响脚本。演练新增表对旧平台无依赖；回退保留新增表与结果，不能 drop 或整库覆盖。
3. 用合成凭据执行 Compose 配置验证；不输出真实配置展开结果。独立环境验证镜像启动、真实 PostgreSQL、普通账号权限、HMAC HTTP API、分页、未知提交接续、停止、重启及单实例。
4. 取得正式手机锁后，候选单机→双机→最多5台完成完整链路；逐帖双遍一致、库存年龄小于既有阈值、任务设置及占用恢复。旧版运行结果不能记成候选验收。
5. 媒体宿主只读执行 D-075 `verify --live`；失败停止，不修复媒体。生产切换/数据库迁移/代理加载及启用定时需要明确发布窗口，本轮只准备。

## 获准发布时的顺序

1. 核对实时占用并排空需要切换的执行任务；按授权切换已测试主平台镜像及必要的采集器候选。保留 ADB/SYSTEM/媒体原状态。
2. 创建专用普通账号及受限配置；备份后应用新增两表 schema。保持计划关闭。
3. 使用同一个 Compose 项目和同一份受限环境，加载根 `docker-compose.yml` 与本目录 `compose.override.yml`，指定 `--profile xhs-batch up -d --no-deps xhs-batch`，不构建、不重建其他服务。先确认既有 PostgreSQL 和主平台健康，overlay 的 depends_on 不是绕过核对的理由。
4. 检查批次 `/healthz`、平台 `batchContract`、名单和普通账号权限。再按已批准的入口变更流程加载 HTTP 代理片段；禁止用 root 临时 Nginx 隔离测试，遵守 `deploy/nginx-isolation/verify.py`。
5. 用正式开放 HTTP API 做获准的小批次验收，结果分页与原任务逐项对账。通过后再显式保存每日02:00计划；观察第一轮自然调度，未经历自然02:00不能宣称已经验收。

## 回退

先通过签名 API 关闭未来计划、停止当前未派发项，等在途任务真实终态；停止批次容器，撤回新增入口片段，按备份恢复主平台镜像及对应采集器。保留两张表、幂等记录、Nonce 和已有结果。旧版不读取新表，不需要破坏性 schema 降级。回退后检查既有任务、控屏、库存与 D-075；不重启 ADB、Windows 或媒体。
