## 变更

- 就绪空闲有效期4分钟。成功姓名和明确空结果刷新最后成功时间；正在执行的原请求不因时钟到期被重派。未知/人工/离线/换号仍失效，不把成功旧结果误用到新账号。4分钟是内部余量，不是第三方风控保证。
- 完成一次5台就绪目标后，无业务、无新的prepare调用时，不持续空刷探测；闲置凭据失效后正常回收。新prepare、未完成业务或设备异常触发补探测，原30分钟准备租期不延长。公开接口字段与HMAC契约不变；503 lookup_not_ready需保留业务键重新准备，文档及下载包同步。
- 人工完成并探测通过的手机获得一次派单优先，成功派出后消费优先标记，后续回到原公平顺序；旧proof失效会清除旧优先。没有可用执行槽位时继续等待，不抢占正在执行任务。
- 人工等待达到上限仅暂停新探测/新未准备会话，不挡已就绪手机接业务。保留人工超时、取消和身份授权检查。
- 候补从已启用、健康、未隔离、未占用手机中挑选；优先尝试近期未试过的健康候补，再考虑复用空闲会话与上次使用时间，减少对坏手机的反复重试。账号全冷却跳过，三次失败隔离仍须原有人工重置流程，不能为补5台自动解除隔离。
