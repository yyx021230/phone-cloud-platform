## 新行为

1. 手动stop或空闲自动结束仍立即停止探测和新分配、取消排队。在线手机照常停止并等待确认。
2. 结束期间连续30秒无法停止的离线手机，先在事务中撤销本会话/代次的未完成自动化作业和Windows任务，阻止旧payload、ACK和迟到状态重新激活任务；持久化成功后才从本轮结束条件中移出。原未完成业务返回failed/lookup_round_stopped，不伪装为空姓名；已收到并完成的结果保留。
3. 手机通道、原代次和物理占用继续保留为quarantined，不是物理停止ACK。旧轮次可以stopped，新准备键可以在其他健康手机启动；至少两台真实探测就绪的门槛不变，没有足够健康手机时仍preparing。
4. 重连后先走同一旧代次的正常stop交付，等待真实停止确认才释放该手机；之后重新探测才能接新任务。清理动作占现有执行槽，上限5；离线隔离不占新轮执行槽。不能把离线未知执行宣称为物理进程已终止或全场实际进程数量可证明。
5. 清理期间再次掉线也有30秒隔离收尾；反复轮询不重复写隔离事务，旧stop重试不会影响下一轮，也不会重新绑定旧隔离通道。线上仍有未知执行但未掉线时保持原停止确认门槛，不凭超时清锁。

持久化失败、会话/代次缺失或冲突时仍拒绝假报stopped。隔离手机不复用，不靠重建ADB、切身份、清锁或删除请求实现解卡。
