## 行为

- 每轮正常工作/待命目标最多5台（配置执行并发更低时使用更低值），正在工作的已验证会话优先保留。
- 空闲候选中，刚人工恢复的优先，其次仍在有效期的会话，再按稳定原顺序；只选择有健康/身份/轮次证据、无未完成请求且执行器明确ready且非busy的多余idle会话。
- 每台在独立事务重新计算选择、校验会话代次及停止能力；通过原stop交付路径停止。停止占执行槽位，总执行最多5；只有真实停止ACK才能释放占用。不删请求或结果，不新增schema。
- 待退回设备不接新查询或重探；停止等待仍保留预约。其他健康手机继续分配。清退失败只回滚该台停止，不回滚已完成姓名；下轮重试。
- 保留手机仍按5分钟原机重探/15分钟整轮空闲关闭。已退回手机可在未来真实缺机时作为候补重新探测。
- 人工、未知、掉线和停止未确认可能暂时使总占用超过5；此补丁限制正常工作/待命集合，不能通过强清锁兑现任何时刻总占用绝不超过5。多客户各自轮次沿用既有独立目标，全局执行上限保持5。
