## 执行与调度

1. 云端领取事务同时保存原任务和独立手机清理义务，再返回绑定。
2. 唯一Python读取器报告实际PID、精确创建token及机器身份；父Agent等持久登记ACK后才下发配置。
3. 执行结束后等真实OS close，再报告host-closed；业务结果单独保存。业务终态、取消、TTL、归档或重启不解除未知义务。
4. 同Agent轮询从持久义务补排首次verify-only任务，不重投原业务；核验失败不无限换代。
5. 只读核验原host、SYSTEM/ADB身份、两包absence及目标serial全部forward为0。两帧从最早读取开始计龄，接收仍须在3秒内；不杀进程、不删forward。
6. 核验子进程真实关闭后上传证明，同原body最多重发一次。云端原子提交核验终态、义务及精确原锁释放；原邀请结果/claim保持。
7. 证明提交后该手机才接新任务，原未知发送/保存仍按原目标防重。失败不触发额外截图或全局扫描。
