## 本阶段变化

- 新 Agent 每次领取任务只读报告实际读取器上限、不能回收的读取器序列号和本次运行 ID。未改变读取器上限8、共享ADB、SYSTEM或控屏流程。
- 云端派发前将报告、运行/停滞任务、未确认的有效投递租约、Agent仍执行或待回传任务按设备取并集；容量不足继续排队，不创建一个必然容量失败的手机执行。
- 原投递代次、占用、排除列表和取消规则继续适用。停止清理、非查名业务绕过新增容量门禁，原有全局任务并发门槛不改变。
- 支持协议一旦声明，写入既有DATA_DIR/lookup-reader-capabilities/下按Agent ID SHA256命名的.v1小型不可变标记，文件fsync、rename、目录fsync完成后确认；不强制大运行快照。存储损坏只阻止相关新查名，目录整体不可读保守阻止新查名，不阻断平台启动/停止清理/其他任务。
- 新协议缺报告、运行ID不匹配、未知活动任务、报告过期均拒绝新查名领取；从未声明的新旧兼容Agent仍显示legacy_unreported，不冒称其已有主动容量保护。新Agent每次poll也声明协议，避免下一次心跳前的降级窗口。
