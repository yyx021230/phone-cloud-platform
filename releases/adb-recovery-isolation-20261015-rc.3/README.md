# 安装器阻塞范围修复 rc.3（本地候选，未上线）

用户要求“别让安装器繁忙阻挡恢复机制”，并明确不重建ADB。延续rc.2单台隔离和独立在线上报；本轮只叠加1个Agent源码及3个测试文件，无云端/依赖/数据迁移变更。

- 修复恢复唤醒在installer busy/unknown时直接返回：仍执行轻量发现/上报，不每次强制全量USB库存。
- 混合队列先筛出需要安装器的PnP动作再占批次名额；单台`adb -s <serial> reconnect`继续，PnP等待单独记录目标及重试时间。纯重连波次无需安装器探测。
- 真正PnP命令在持久化后、执行前重新核对安装器；若变忙/未知则还原未消耗的尝试状态，不记录命令失败或持有设备锁。随后再次核对暂停/快照/设备占用。
- 保留全局故障熔断、设备暂停/隔离、未授权及占用保护；不允许对missing transport或unauthorized强行套用reconnect。Windows安装器仍可能最长10秒有界探测，未宣称零延迟。

**限制**：依赖Windows驱动的重启/重装/端口动作仍等待安装器空闲；本补丁不消除OEM共享co-installer冲突，不处理手机端授权。生产最近16:07为deployed.10，而组合源码基于rc.8→rc.2；发布前必须按线上实际文件最小合并，禁止整仓覆盖。

验证：根check、797/797全量test:screen（0跳过），其中21项定向行为验证；27份冻结文件与控屏/ADB启动片段未变。Windows原生、真机、生产及长期稳定性未验。当前不部署、不推送、不启动/重建ADB，不改身份/授权/启动入口。
