## 已确认缺陷与修复

1. Agent停止常驻读取器返回false或抛错，旧入口仍返回session_stopped。现在stop先走清理专用分支，不启动读取器、不查安装包、不读取/点击页面；只有手机端读取器与转发清理确认才成功。
2. 云端旧逻辑把停止任务failed/cancelled也结束会话，并把failed会话当物理停止。现在必须收到成功状态及匹配taskId、sessionId、deviceId、generation的清理证明。迟到任务不能清空新pendingJob或释放新占用；准备失败也不能直接释放受管会话锁。
3. 清理未确认保留原查询和占用；间隔30秒补试清理，最多两次，重启本地服务仍保留次数。清理确认后才能按既有恢复策略接续；不重复输入号码或伪造空结果。
4. 原离线30秒持久隔离/代次栅栏逻辑保留。在线但清理不明的手机仍不能靠超时假称已停止。两次补试仍失败会保留占用待确认，不能宣称已经彻底消除所有stopping阻塞。
