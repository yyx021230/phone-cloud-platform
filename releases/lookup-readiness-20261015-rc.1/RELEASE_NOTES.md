# 本轮更新

- 增加准备接口和每账号、每Agent进程、每会话的就绪证明，2台通过即可接业务，后台目标5台；准备与业务共享5路上限。
- 仅已探测正常的手机查正式号码。确认触限先冷却ACK、结束旧执行，原lookupId转交另一台正常手机；受限手机后台切号重新探测。无可用手机等待，状态未知不盲目重放；迟到结果、取消、原请求防重均保留。
- 新启动模式完成仅name有姓名或空字符串，未实名为空。充值入口空结果增加已验证账号、原号码匹配、完整稳定两帧和保护状态排除；异常仍为独立服务失败，不污染空姓名。
- 新prepare/submit/result文档、OpenAPI、Node/Python SDK和可运行合作方持久回填示例同步；其他平台模块分类保留。47个平台操作、11个查名HMAC操作。
- 无数据库迁移、依赖升级、生产配置修改；没有合入单台恢复暂停功能。投屏及D-075冻结文件24项原样保留。
