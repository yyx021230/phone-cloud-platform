## 行为

- 新轮次初始空闲截止为启动时间+600000ms。业务入队与暂停空闲计时在同一持久化事务中完成；排队、执行、人工等待、恢复、未知执行、停止待确认均算未完成业务。
- 最后一条业务结束后重新计完整10分钟；同键重试、已有任务/缓存复用、GET和prepare轮询不续期，换prepare键也不延长当前轮次。后台探测不算业务活动。
- 自动结束复用已发布round-stop的停止确认屏障：阻止新分配/探测，停止空闲或探测会话；未知/离线未ACK仍保留占用，不伪造stopped，不动其他客户。用户主动stop仍立即生效。
- expiresAt有未完成业务时返回null；空闲时为UTC截止时间，公开schema及HTTP文档同步。外部只需按status/ready判断，不用计算租约。到期可能短暂expired，随后stopping/stopped；确认stopped后新prepare键开启下一轮。已完成结果保留；普通Python/Node示例不在expired状态自动重开。
- 旧存量尚有效轮次首次维护时迁移一次，空闲时给予10分钟；已过期且无业务的旧轮次直接安全结束，已有业务受保护。新字段保存在现有managed JSON，无DDL，重启保留计时和停止屏障。
- 单项排队30分钟、总执行60分钟、人工等待30分钟等既有限界保持；后台单次探测有独立30分钟预算（不是轮次寿命），无业务时仍受10分钟自动结束约束。4分钟手机就绪证据新鲜度不变，不能承诺连续免验证。
