## 本轮行为

仅在已执行号码查询、同机只读恢复仍失败并进入“页面待兼容”时，读取该原查询的持久化截图。启动探测、拼图、切号、登录、冷却、设备离线不交给模型判断。绑定lookupId/queryId/session/device/generation/失败任务/截图SHA256；错单或失效回调不写回。

使用用户指定服务的`gpt-6.1-sol`，最多5路独立推理。网络不占用协调器事务；**整个AI阶段最多120秒**，不再叠加第二次读取等待。130秒持久租约只供进程中断后的对账，正常调用120秒即收尾；缺少上传截图只等10秒，然后按未取得姓名收尾。

对外沿用原成功终态和原lookupId，只返回原姓名显示或空字符串。未实名、无姓名、无法确认、超时、接口失败均`""`，不扩展状态/字段/错误码。空字符串在此点包含无法确定的情况，不承诺它证明号码无实名。既有已完成结果、终止、权限或其他业务错误不改。

明确读取姓名/未实名/完整无姓名，且原账户身份未变、原进程的探测资格仍可验证时，原机直接接下一单。AI不创造新的探测资格。未知/超时、身份或进程变化时先保存业务结果，再按原有停止ACK释放，不能删锁假装手机停了。离线继续使用原来的隔离/回收机制；取消/结束/迟到结果都不能重新唤醒旧查询。

模型配置缺失/读取失败不会让整个平台启动失败；已启用的此兼容点会有界结束为空。密钥只放云端源代码目录外的root私有secret，通过只读挂载提供；不下发Windows、前端、任务载荷、Git或日志。
