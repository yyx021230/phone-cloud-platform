## 证据与边界

## 最小改动

共享exit helper、focus、ADB调用封装均不修改。仅在冷启动已证受限Search、执行原有退出步骤后，补一层焦点稳定观察：

- 只有缺失/null焦点，且底层activity为空或属于支付宝时，允许只读观察；具体第三方窗口、SystemUI或支付宝弹窗均立即交回原Home拒绝逻辑。
- **新增**2秒monotonic观察预算、最多8次focus读取。每次`dumpsys window`调用timeout不超过0.5秒及剩余预算，recover=False，禁止进入focus原有10秒/3秒恢复分支；既有ADB封装在这个短预算内不会再等待0.5秒重试。最多8次新增只读ADB命令，不增加Back、点击、滑动、启动或号码输入。
- 这是新增观察阶段的预算，不是整个准备步骤的2秒硬超时；原退出步骤、系统调用调度与事件记录耗时不包含在内。不改变共享ADB身份、二进制、端口、key或服务。
- 到首页后仍要求原XML首页、拼图及账户marker证据；缺失或歧义仍拒绝。脱敏记录home/non_home/unresolved/read_failed、采样数和观察时长，不记录账户或号码。
