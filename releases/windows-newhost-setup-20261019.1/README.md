- 系统可选组件中的 sshd 7.7.2.3 与客户端 9.5.2.1 不一致；服务不能启动，直接诊断退出 `0xC0000139`。这证明组件异常，但不把尚未定位的具体缺失入口当成已确认根因。
- 原 FOD 文件复制到新机 Administrator 下载目录下的 `openssh-fod-backup`；系统目录原文件未覆盖。
- 从 [微软 Win32-OpenSSH 官方发布](https://github.com/PowerShell/Win32-OpenSSH/releases/tag/10.0.0.0p2-Preview)取得配套 ZIP。5,704,583 字节，SHA256 `23f50f3458c4c5d0b12217c6a5ddfde0137210a30fa870e98b29827f7b43aba5`，Mac 与新机一致。发布标签包含 Preview，记录原样保留。
- 安装器、sshd、ssh 和 libcrypto 的 Microsoft Authenticode 签名均为 Valid。签名安装器以单次信任运行，没有持久变更执行策略或添加可信发布者。
- 安装位置 `C:\Program Files\OpenSSH-Win64`。官方安装器重新注册 sshd/ssh-agent、处理 SSH ACL/ETW/RedirectionGuard 和 PATH。sshd 已启动并设为 Automatic，ssh-agent 未启动。无 Windows 重启。
- 向日葵读取的 ED25519 主机公钥与 SSH 首连指纹一致后才接受主机密钥。绑定 Mac 公司网卡直连成功，不改全局 VPN 或路由。
- 一次 Administrator 密码认证被拒，OpenSSH Operational 同时记录 Failed password；账户启用且要求密码。未取得完整 Security 4625 子状态，不能进一步断定具体拒绝原因。未反复重试或更改密码，等待用户确认。
