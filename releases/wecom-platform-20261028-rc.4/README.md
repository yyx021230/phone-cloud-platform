## 回退边界

本轮没有生产变化需回退；本地可在新worktree读取rc.3，保留本分支和旧标签，不重置用户改动。rc.2/rc.3都未上线，旧暂存镜像不是本候选；后续需以当时实际线上基线重新打包全部20文件、备份、安排维护及真机灰度。

未来若已部署v3，自定义任务未终态、写入未知或子进程未结束时，不得直接回退到只认识默认备注的旧云端/Agent。先停止新增派发，核对原任务、worker和锁安全收尾，保留结果；无法证明时停止回退，不能把自定义任务重新交给旧执行器。正常业务回退仍不得重建ADB、切身份或触碰密钥、Windows、USB、媒体及D-075基线。
