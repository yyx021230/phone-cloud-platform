# R2 自审记录

2026-10-21，由本轮开发者自审，没有独立审查人，不作为生产发布授权。

检查范围：父候选之后全部运行差异、调用链和测试夹具；父候选执行器恢复分类继续继承。基线、完整哈希、实际测试和失败记录见同目录JSON/TAP。

- 云端观察租约仍校验Agent、设备、挑战、控屏会话、顺序与30秒时效。恢复前再次校验sessionId/deviceId/challengeId/screenSessionId；重启生成新owner，旧阳性观察不可直接恢复。观察成功不代表已重查，不提前向外部完成业务。
- 调度先对账终态/停止/结束，再续接已确认人工，之后派业务和探测。未ACK的旧执行不重放；离线隔离沿用既有持久fence。业务幂等仍由原异步层负责，新业务分配序号与请求/渠道同事务提交。
- 人工长等补位仅无控屏且能够安全停止时触发；等待ACK保留预算，候补未就绪不承接业务。超过2分钟不等于取消外部号码；它是内部安全补位策略。旧超额执行保留保护，不假称即时收敛到5张卡片。
- 触限记录后原机只获得一次优先探测，原业务转交仍须ACK；已掉线账户、全部冷却、不健康设备不因此绕过资格。5分钟原机刷新和15分钟空闲关闭保留。
- 新卡片接口使用既有平台登录认证及库存可见性；只返回固定状态字段。DOM仅更新状态占位区域，退出/切用户时丢弃旧响应，无HTML插入未转义的设备/状态文本。没有调用、重建或修改控屏会话。
- Agent只读观察器与业务执行互斥，复用worker前检查pending/stopping/readyResolve；失败退避后不创建或重启worker。最多3个只读观察，总量不因detached轮询叠加。迟到上报有服务端租约与挑战保护。
- AGENT_SCOPE证明入口除两处观察区域外逐字不变；FROZEN覆盖媒体、控制、ADB辅助文件等361个未改文件。完整既有screen/Agent回归通过，但仍不能替代Windows真机并用验收。
- 没有修改依赖、数据结构、生产配置、ADB身份/路径/端口/授权key。JSON快照恢复完整保留；回退不得换回JSONB或恢复旧数据库。

审查结论：本地候选范围明确，可进入后续获授权的上线准备和单机/双机灰度。无已知未解释的本地测试失败。真实手机检测延迟、观察负载和自然触限表现未验证，不承诺消除支付宝拼图。上线需要云端和共享Agent加载新代码，必须另核对生产漂移、备份、D-075 live及当前控屏维护范围。
