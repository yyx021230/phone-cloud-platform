## 完整性与身份边界

- 全程原生元素，未使用OCR/图片识别或帖子详情。
- 同名同日两篇不能按标题日期合并。封面元素的sign/t/ext会在重新打开数据中心后变化，不能当永久笔记ID；只保留任务内SHA256，不输出原始签名文本。
- 有同名同日笔记时，第一遍从新到旧完整采集，随后在同一列表中向上重新读取每篇身份，核对连续位置、反向跨页衔接、末尾日期/结束边界及原生顶部。少帖、重复、换序、身份变化或无法证明边界都会报不完整。
- 其他账号沿用标题/日期的两遍身份规则。结果新增方向标记；摘要算法见 `docs/XHS_BATCH_API.md`。
- 这是对页面可见列表的完整性证据，不能证明服务端没有隐藏帖子。账号昵称/小红书ID仍来自平台绑定快照，未新增实际登录账号身份核验。
