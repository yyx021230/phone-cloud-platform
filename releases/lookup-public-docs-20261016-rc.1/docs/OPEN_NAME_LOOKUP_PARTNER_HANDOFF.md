# 开发对接交付清单

1. 平台单独提供 BASE_URL、clientId、secret；凭据仅保存在调用方后端。
2. 按 README 的三个接口接入：启动准备 → 提交手机号 → 获取结果。
3. 准备键、业务键、lookupId持久保存；两分钟超时继续按原ID读取。
4. completed时保存name；没姓名/未实名为空字符串。处理中或异常不能写空。
5. 默认最多20条未完成请求，429稍后重试；503 lookup_not_ready先重新读取准备状态。
6. 联调覆盖：签名、准备就绪、有/无姓名、逐条完成、超时重试防重、回填失败重读。

包内OpenAPI只列出上述三个接口；示例不会自动选择设备、切号或执行人工验证。实际设备可用性与本轮验收进度由平台确认，不承诺每次查询的完成时长。
