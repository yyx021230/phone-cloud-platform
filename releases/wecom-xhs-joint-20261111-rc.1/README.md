# 企微与小红书联合发布候选

企微包含 200 和 202 的清理复核和 Windows 只读 TCP 观察器。小红书包含管理后台采集日志页、原始失败原因和独立飞书掉线通知。候选以 11 月 10 日已上线的企微主平台镜像为生产基线，并采用按生产文件哈希复核的小红书页面差异。部署清单记录独立通知进程已核对的版本。每日 02:00 采集、媒体和 ADB 保持原配置。

部署前核对现网镜像、Compose 和文件哈希，等查名队列、Windows 在途任务和小红书批次排空。切换主平台到联合镜像，原有小红书采集和通知进程继续运行。加载 Windows 的单文件观察器，复查健康、查名、后台日志页及真实媒体宿主 D-075。

两台手机的复核需要原任务的真实清理证明。先确认 202、200 均释放，再分别在隔离预览账本中执行。两台都通过后，通知用户让 CPS 开发下发一条获授权的新测试线索。正式链路使用独立账本，以 CPS 的业务应答为回传通过依据。

现网版本由部署回执绑定。当前候选处于准备阶段。回退材料以 11 月 10 日当前线上版本为基准留存，任何回退需遵守用户本轮指示。
