## 风险与交付

本轮Agent入口仅改查名错误分类和查名Poco失败兜底策略，不改共享ADB、生命周期、媒体或控屏实现。后续若部署，须整体带上新增server/lookup-reader-capacity.mjs及配套入口，不能只替换index。共享资源等待会降低反复无效启动，不能增加物理能力；持续资源满时仍需要容量观测与验收。

新持久字段readerCapacityBackoffs为Agent组短期退避，lastCapacityFailure只作内部证据；不新增外部接口、密钥或响应结构。原ID幂等、停止ACK、隔离和冷却保护不放宽。已有其他原因造成的历史隔离不会被本补丁全量清除。
