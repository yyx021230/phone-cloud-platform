## 交付内容

对方只需POST提交手机号、保存lookupId，再GET逐条获取姓名。内部49台名单/最多5台并发、账号冷却和人工接续沿用原设计。本轮没有更改线协议、数据表、调度、Agent或媒体。

- Node/Python SDK修复构造器超时被新方法默认值覆盖的问题。
- Python补齐响应正文断开、缓慢响应头/正文的超时与错误分类；网络提交仍原键最多重试一次，GET不触发新提交。已知HTTP失败保留状态，非JSON/非对象成功响应不再误报成功。
- 两种SDK暴露Retry-After秒数，便于429退避；503不自动重提。
- 接入包增加 `PARTNER_HANDOFF.md` 和可运行 `partner_example.py`：提交前持久保存业务键，进程崩溃后复用，逐个结果独立落库，回填失败不重查；有界轮询轮换记录，前面的慢任务不长期挡住后面的结果。
- 明确去重边界：同客户同号码在途合并、近期成功/明确无姓名固定10分钟复用；失败确认停止或缓存到期后，新键可创建新业务。同一业务永久防重应持久复用原键。
