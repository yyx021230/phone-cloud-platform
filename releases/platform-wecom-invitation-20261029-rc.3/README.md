## 给对接方的流程

[简版接口文档](../../docs/wecom-integration-api.md)：

1. GET `/api/v1/wecom/devices?onlineOnly=true` 查全部在线手机及占用；去掉参数包括离线手机。
2. 选择available=true的手机及返回的main/clone，在capacity.remaining>0时按原四字段POST创建邀请。
3. GET原taskId查结果；未知发送不重发。

设备视图包括编号、名称、在线/ADB/Windows Agent状态、上架、忙碌与原因、占用类型、是否配置企微、已验证账户列表、单机可用性、剩余任务容量及机型/电量/原上报时间。全部在线并不等于全部开放企微，目前8台及2任务限制不变。列表是快照，不预留设备；提交时仍复核，竞态409/429正常处理。available不保证已登录或免验证。
