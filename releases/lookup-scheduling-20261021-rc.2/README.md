## 此次优化

- **状态以新证据为准。** 真实拼图显示需人工；正常页首次检测显示“正常页面 · 复核中”，同挑战两次确认后显示“验证完成 · 等待接续”。30秒过期或未知显示检测中，不能拿历史人工事件一直要求用户拼图。
- **息屏单独显示。** 观察器通过既有受保护ADB调用只读 `dumpsys power`，2秒超时；页面读取前确认亮屏，正向页面证据后再次确认。息屏跳过页面读取，不唤醒、不点击，不把黑屏当拼图或完成验证。多个电源组的状态必须全部一致；冲突、缺失、错误保持未知。
- **检测过程可定位。** 内部记录最近检测时间、有限枚举原因和0–30000ms耗时，区分设备忙、页面未知、电源读取失败与页面读取失败。不上报号码、姓名、原始页面或错误文本。停止、账户掉线和正在接续优先级不变。

本轮增量8个运行文件、6个测试文件和1个HTTP验证脚本；完整名单及哈希见 MANIFEST。相对rc.1的332个范围外文件哈希保持；Agent入口仅观察器初始化增加只读电源回调，其他入口代码逐字相同，证据见 AGENT_SCOPE。没有修改ADB身份/密钥/路径/端口/启动方式、共享生命周期、控屏或D-075媒体参数，没有SQL迁移、依赖升级或对外接口契约变更。新回调是在候选代码内，未在生产执行。
