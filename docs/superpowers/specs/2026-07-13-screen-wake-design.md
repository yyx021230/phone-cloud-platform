# 投屏唤醒屏幕设计

实时控制建立后自动点亮手机屏幕，并在工具栏提供“唤醒屏幕”按钮。自动和手动操作都复用现有 Browser、Server、Windows Agent、scrcpy 控制通道，先显式设置屏幕电源模式为 `Normal`，再注入 Android `KEYCODE_WAKEUP`（224）。两步都是明确开屏，不会把已亮屏幕关闭，也不自动解锁。

尚未投屏时点击“唤醒屏幕”会先建立投屏，控制器就绪后自动唤醒；投屏已连接时按钮直接发送 `key: wakeup`。自动唤醒失败只记录日志，不终止视频流。

验收标准：熄屏手机启动投屏后自动亮屏；亮屏手机不会被关闭；手动唤醒可重复使用；原有触控和系统导航保持正常。
