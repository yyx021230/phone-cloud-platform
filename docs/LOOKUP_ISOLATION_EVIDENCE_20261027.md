## 已确认原因

1. **技术故障进入设备隔离**：生产 `lookupFailureDomain` 将HTTPConnectionPool/worker退出归device；失败截图AI只接受page域。138、142、155、158的原图实际有姓名，却在读取超时分支结束，未进入这一截图AI入口。这是执行/恢复和分类链路问题，截图不能证明账号当前受限；也不能据一次旧截图直接授予现在的就绪资格。
2. **旧隔离长期保留**：生产lookupUnavailable为持久布尔；quarantineUntil到期并不会清除。13台中8台隔离来自10/23，2台10/26，3台10/27。仅凭当前隔离卡无法断言手机仍故障。rc.7继承的受控重探仍是本地候选，尚未上线。
3. **后台历史证据查询缺口**：生产overview与job详情只查询state.automationJobs/windowsTasks。13个隔离job详情，11个实际HTTP404，142/192返回200；然而13个都能按主键从Postgres归档取回。11台overview的lastFailure为空。生产状态保留有界任务集合，旧隔离记录仍存在、旧job已不在当前集合，详情没有归档回查。
4. **并非都没截到图**：7台归档finish事件有screenshot证据及原图数据，本轮成功恢复并逐张查看；其中5台（138、149、155、158、188）后台详情404，另2台可显示。其他6台最后隔离任务无截图记录，不能补造当时画面。错误栈被截断时也不能猜测底层故障。

- 持久保存每次实际计数事件的阶段、时间、错误类型、恢复尝试与证据引用，准确展示三次计数链；无图明确显示“未取得截图”及已知原因，区分归档不可达、证据缺失、采集失败。

## 继续追溯：读取超时与进程退出的因果边界

本轮从 Windows 实际运行目录只读获取 index、Poco worker、查名脚本、页面恢复和停止策略，按13条隔离任务时间定点读取 agent.log（单文件约1.23GB；时间定位后每窗最多8MB，不全量拉取）。启动探针、手机状态和共享服务没有被本次调查改变。生产 index SHA256 `eafc722b93788d82bc788ed79f963b17224b2d8c30528bfbfbcedb83fe9a9dd2`，查名脚本 `30e0c828d981f1e9fd9c62d6b6e48141c7c13ae25c5e899d68992ce04d2df024`。

### 已确认的代码缺口

1. **视觉读取仍被同一个元素通道中断。** 生产 `poco_visual_result_readonly` 的4010、4064行分别在截图识别前、后执行 `poco.freeze()`，均在视觉异常转换的try范围外。后一次失败会丢失本轮尚未确认的候选结果，并泄漏原始RPC异常。142在03:59:33.132 UTC完成OCR帧读取，03:59:35.238报2秒RPC超时；154亦在帧读取后约2秒失败。时序与代码一致，但无完整调用栈，不能声称已证明这两条必定是后一次freeze。
2. **原始读取异常走应用重启。** `canRestartLookupAfterFailure` 对未带 `local_lookup_` 等边界标记的query原始RPC超时返回true；恢复流程停止worker、启动应用，再停止/重建worker接续。已经输入号码的视觉检查异常可能进入此路径。rc.6/rc.7修复的“输入前标记及大小写匹配”不能据此宣称覆盖了这个输入后的缺口。保持原结果/输入/截图关联与限制、拼图检查仍必须，不建议简单删除结果安全校验。
3. **正常停止预算与实际清理不匹配。** 生产普通lookup恢复只给300ms优雅停止；Python清理包含端口移除、两个包force-stop、固定250ms等待和pid复核。日志反复出现300ms后forcing、forced=true。故障后的恢复存在明显强杀放大因素；它发生在首次超时之后，不能倒推是所有首次超时的原因。rc.7实际payload仍为300ms，没有修复此项。控屏分支5000ms与冻结约束保持，未来改动必须单独评估共享生命周期影响并跑投屏回归。
4. **启动检查失败直接退出，底层错误又被截断。** `verify_worker_adb_transport` 连续两次执行有界shell检查仍失败后抛出异常，位于worker结构化启动异常处理之外。51/52/146/153/154先有RPC超时，重建后退出栈经过该检查；192只能确认快速退出，不能套用相同原因。生产分类器只保存异常前500字符，Python异常尾部丢失；child exit没有独立保留退出阶段及脱敏尾部。因此现有记录无法判定这些ADB检查究竟是超时、离线还是其他拒绝。
