# 公开源码快照说明

本仓库采用独立根提交发布，不包含私有开发仓库的提交历史。

## 已包含

- 平台服务端、浏览器前端和测试；
- Windows Agent 源码、自动化脚本和测试；
- Android SmsRelay 源码；
- 媒体发布器、节奏控制组件和测试；
- 通用 Docker、Nginx、SQL、systemd 示例；
- API、Open API 和部署说明。

## 未包含

- 生产数据库、JSON 状态、日志、缓存、截图和元素树；
- `.env`、Windows Agent 本地配置、令牌、密码、Cookie、私钥和签名文件；
- 真实手机号、设备序列号、内部网络地址和生产资产清单；
- 生产事故证据、内部决策流水账、课件和演示素材；
- 一次性生产合并、热修和设备操作脚本；
- ADB、scrcpy、FFmpeg、Windows 可执行文件等第三方或预编译二进制。

文档和测试中的地址、手机号、设备编号均为示例。部署前必须重新生成凭据，并根据自己的网络与设备环境填写配置。
