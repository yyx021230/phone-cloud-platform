## 方法

使用用户指定服务、请求模型 `gpt-6.1-sol`，`/v1/models`实际返回该标识，Responses图片请求实际成功；这只能证明该服务公开模型ID可调用，不能独立证明其内部路由实现。图片以base64数据URL发送，`store:false`，无工具/手机操作。格式参考[OpenAI图片输入文档](https://developers.openai.com/api/docs/guides/images-vision)。用户提供的密钥由隐藏输入读入测试进程内存，未写入文件、命令参数、Git或报告；没有改生产密钥配置。

有姓名四图每图发起两次独立读取，同一原图共8次请求；两次答案一致且与操作员先前核对一致。请求提示不提供目标手机号供模型照抄，由模型独立提取搜索框及每张卡自己的号码、昵称/掩码姓名、按钮与位置，再在本地核对原订单号码。不能推断星号遮盖文字。多卡要求各自号码、按钮和姓名边界完整、掩码尾字一致；保留第一张完整卡的原样显示名，不拼凑完整真实姓名。

十二反例各1次模型请求，共20次实际推理、16个场景、15张不同图片（错订单复用181原图）。反例除核对原号码，还以模型自行报告的号码再次验证，避免仅因测试用了其他号码而虚假通过。未向支付宝提交测试号码；唯一新增生产读取是下载已保存的拼图失败截图，未获取实时控屏或执行手机动作。证据含手机号/姓名，原图和模型原始输出留在本机私有临时目录，不入Git。
