1. 维护前只读确认ACTIVE、云端与Windows实际文件、155原job/task/义务、其他活动查询和控制连接。对原记录备份；只用原主键有界读取，不能扫描payload。保存旧SYSTEM Agent的PID、精确出生token、Windows MachineGuid的现有哈希与可执行/入口/身份、现有SYSTEM ADB PID/出生/路径/监听。凭据不落盘。
2. 取得本次云端业务与共享Agent维护窗口授权。等待已有查名任务和其他业务安全收尾；无法安全收尾则继续等待，不抢占或取消。共享重载会影响控屏连接，必须先确认；不关媒体、ADB、Windows或USB，不改SYSTEM、二进制、端口、key或启动入口。
3. 用已审查的完整WeCom协议闭包构建、备份、审核生产32c到候选的实际差异，不能整仓覆盖。云端和Agent必须配套加载，原有CPS桥接仍不启用、映射待补。本轮标签不是发布授权；D-075真实媒体宿主`verify --live`发布前后只读核验仍必需，失败停止。
4. 确认旧Agent进程代次确已退出，新SYSTEM Agent与共享ADB身份不变。**旧Agent引用来自维护前的实际观测，不是原reader的替代记录，不允许猜PID。** 无法证明观测来源、主机不同或旧代次仍活着，停止。
5. 具有非空userId的管理员登录会话发起维护，不能用无用户身份的旧ADMIN_API_TOKEN执行POST。旧原单的job/lock均为空owner时仍保留该事实，不能补造历史用户。管理员GET读取155义务恢复提案，审查原任务指纹；POST携带原指纹、唯一requestId、旧producer引用及明确维护确认。新Agent能力必须在30秒内新鲜；旧Agent不能领取任务。物理围栏保持，任务不包含客户号码、备注或发送能力。
6. 新Agent私有只读worker证明新旧producer代次不同、同主机、旧代次退出、只有一个当前Agent。每帧及固定ADB操作前检查身份和进程；所有WeCom Python进程必须不存在，未知Python/读取失败停止；允许现有查名及OCR worker继续，且不对它们发命令。通过现有Windows只读TCP表读取器核验实际5037反向连接的SYSTEM ADB进程、路径和出生代次后，才发送固定只读命令。

## 内部维护接口

这些接口不属于CPS三个业务接口，不向外部客户开放管理员凭据。

- 管理员`GET /api/v1/admin/wecom-cleanup/{obligationId}/preinput-recovery`：只读提案，不派发、不清锁，不返回客户号码。
- 管理员`POST`同路径，严格字段：`protocol=wecom-preinput-recovery-v1`、`requestId`、`fingerprint`、`retiredProducer={pid,creationToken,machineId}`、`acknowledgeMaintenance=true`。同一操作者同一正文只复用原attempt，改请求号/引用拒绝。
- Agent内部`GET .../windows-agents/{agentId}/wecom-cleanup/{obligationId}/recovery-lease`，查询参数verificationId/verificationNonce/verificationTaskId；`POST recovery-challenge`及`POST recovery-proof`。Agent凭据绑定原agentId；不能使用普通task succeeded跳过proof。
- 任务仍用`wecom_cleanup_verify`，新增严格payload标识；poll要求`wecomPreinputRecovery=wecom-preinput-recovery-v1`，与现有causal能力同时满足。

## 报错与处置

| 错误/情形 | 具体含义 | 处置 |
|---|---|---|
| recovery_operator_required | 发起者没有可审计的用户身份 | 使用真实管理员登录会话，不把旧原单owner填成新用户 |
| recovery_ineligible | 不是已确认的legacy预览登记前失败，或原证据缺失/变化 | 保留原锁，查原主键；不按本流程强行恢复 |
| recovery_context_changed | 提案后的原记录/设备映射变化 | 停止并重新审查，不盲目沿用提案 |
| recovery_agent_upgrade_required | 没有30秒内的新Agent恢复能力 | 等配套加载与新鲜poll，不绕过 |
| recovery_device_busy / lease_lost | 同物理设备有查名/控屏/其他任务，或租约不再有效 | 等空闲，保留原义务，不抢占 |
| original_host_still_alive / producer_not_retired | 维护前旧Agent代次还活着，或当前父Agent就是旧代次 | 停止；没有批准的完整维护不能继续 |
| recovery_worker_present / processes_unconfirmed | 仍有企微或未知Python进程，或进程读取不明 | 保留围栏，只读取证，不能杀其他业务 |
| recovery_machine_mismatch / peer_unconfirmed | 主机或实际ADB连接对端身份无法证实 | 停止，不切ADB、不换key |
| reader_still_present / forward_still_present | 155上工具包PID或任意转发仍存在 | 停止，不自动停止工具或删除转发 |
| verify_timeout / causal_context_unconfirmed | 3秒证明预算、120秒租约、服务代次等失效 | 不放宽预算、不复用旧proof |
| storage_unavailable | 写入失败、回读不一致、提交未知 | 保留内存围栏；核对原持久记录和同份proof，不能重跑业务 |
