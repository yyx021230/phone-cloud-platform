## 行为

| 项目 | 实现 |
|---|---|
| 每轮等待 | 45秒单调时钟预算；本轮元素准备好即可继续 |
| 读取间隔 | 原生读取之间最多等待2秒，实际读取本身另耗时 |
| 内容确认 | 两次连续完整六字段签名相同；字段缺失或变化继续等待 |
| 入口重试 | 超时后最多重新进入2次，整次任务共享预算；旧备用入口恢复也占用预算 |
| 重入依据 | 只有已证明的数据页，返回后重新证明创作中心及入口元素，才再次点击；动作前核对前台和请求槽位 |
| 扫描开始后 | 只等待/重读，禁止返回重入或切换作品页签，避免重置位置 |
| 停止条件 | 占用、登录失效、账号异常、服务错误、未知前台、读取或清理失败不作为普通慢加载继续重试 |
| 超时边界 | 45秒限制启动后续读取；已经执行的原生读取沿用自身超时和清理，不是整个任务严格135秒上限 |

仍只读原生元素，无OCR、截图、抓包或帖子详情。未改滑动距离、滑动时长、去重、日期边界和既有相邻页身份交集校验；该交集不是连续有序多行证明，不能承诺绝对无遗漏。
